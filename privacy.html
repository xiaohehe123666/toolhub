ToolHub 隐私政策

一句话版：ToolHub 的所有工具都在你的浏览器里本地运行，本站不收集、不存储、不上传任何你的数据。

最后更新2026-09-27
01

我们收集的数据：没有

ToolHub 是一个纯本地工具站，没有账号体系、没有服务器后端。你输入到任何工具里的内容（JSON、代码、文本、密钥等）只在当前浏览器的内存中参与计算，关闭页面即消失。

  • 不注册、不登录、不创建账号，我们不持有任何能识别你身份的信息。
  • 不设置跟踪型 Cookie，不使用任何分析统计脚本（无 Google Analytics、无埋点 SDK）。
  • 不记录访问日志，不收集 IP 地址、设备信息或浏览行为。
  • 工具处理的内容不上传、不出本机；「数据不出浏览器」不是宣传语，是架构事实。
02

数据在哪里处理

所有计算都发生在你的设备上：

  • 格式化、转换、对比、统计等纯文本处理由页面内 JavaScript 完成。
  • 哈希计算使用浏览器内置的 Web Crypto API 在本机完成，不经过网络。
  • JWT、Base64、URL 等编解码同样只读本地输入。

唯一的例外：部分页面会从 CDN（jsDelivr、自托管字体镜像）加载公共库文件与字体，这是所有网页加载静态资源时的常规行为，加载过程不包含你的任何输入内容。

03

你主动联系时提供的信息

通过「客服」页发邮件（feedback@toolhub.dev）或到 GitHub 提交 issue 时，你主动提供的信息（邮箱、反馈内容）由对应的邮件服务与 GitHub 平台处理，用于答复你的问题。这些信息只用于回复本次沟通，不会用于其他用途。

客服页的反馈表单不会把内容提交给任何 ToolHub 服务器——它只是帮你拼好邮件、唤起你的邮件客户端，发送行为由你本人完成。

04

第三方链接

页面中可能包含指向外部网站（如 GitHub）的链接。点击离开本站后，你与那些网站之间的数据传输受它们各自的隐私政策约束，与本政策无关。建议你在提供任何信息前阅读对应网站的隐私政策。

05

未成年人

ToolHub 面向一般用户提供通用工具，不面向儿童设计，也无意收集任何人的个人信息——包括未成年人。由于本站不收集任何个人信息，因此不存在未成年人个人信息被采集的问题。

06

政策更新

若本站架构或数据处理方式发生变化，本页面会同步更新，并更新页首的「最后更新」日期。重大变化会在首页或更新日志中提示。建议定期查看本页面。

07
